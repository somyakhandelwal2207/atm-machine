# ATM Machine Simulation System

## Problem Statement

Traditional ATM systems provide services such as checking balance, depositing money, withdrawing money, transferring money, and changing PINs. This project develops a simple ATM Machine Simulation System using Python to demonstrate these basic banking operations in a software environment.

## Scope of the Project

The project simulates the basic functions of an ATM. Users can create an account, log in using an account number and PIN, check their balance, deposit and withdraw money, transfer money, view account details, view transaction history, and change their PIN.

## Target Users

The system is designed as an educational project for students and beginners to understand how an ATM system can be implemented using Python programming concepts.

## High-Level Features

- Account creation
- User login and authentication
- Balance checking
- Money deposit
- Money withdrawal
- Money transfer
- Account details
- Transaction history
- PIN change
- Input validation
- Logout
