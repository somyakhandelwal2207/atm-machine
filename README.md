# ATM Machine Simulation System

## Overview

The ATM Machine Simulation System is a Python-based project that simulates basic ATM operations. It allows users to create an account, log in, check their balance, deposit and withdraw money, transfer money, view account details, view transaction history, and change their PIN.

## Features

- Account creation
- User login and authentication
- Balance checking
- Deposit money
- Withdraw money
- Transfer money
- View account details
- View transaction history
- Change PIN
- Input validation
- Logout

## Technologies Used

- Python
- VS Code
- Git and GitHub
